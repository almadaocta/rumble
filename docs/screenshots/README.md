# Screenshots

The root README expects these four files. Filenames matter — replace, don't rename.

| File | What to capture |
| --- | --- |
| `dashboard.png` | The Today tab — training load, readiness, next session |
| `chat.png` | A coach conversation where a specialist was clearly consulted |
| `calendar.png` | The Calendar tab — planned vs. completed |
| `nutrition.png` | The Nutrition tab — fueling against the day's demand |

Capture at a 16:10 window, retina if you can (they render at half width in the
README table, so 2× looks crisp). Trim browser chrome.

For the video: drag the file into any GitHub issue or PR comment, let it
upload, then copy the generated URL into the Demo section of the root README.
