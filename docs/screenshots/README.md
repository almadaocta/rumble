# Screenshots

The root README expects these three files. Filenames matter — replace, don't rename. Each should show the coach chat panel alongside the dashboard tab, mid-conversation with a specialist visibly consulted.

| File | What to capture |
| --- | --- |
| `1.png` | The Today tab — training load, readiness, next session |
| `2.png` | The Nutrition tab — fueling against the day's demand |
| `3.png` | The History tab — planned vs. completed |

Capture at a 16:10 window, retina if you can (they render at half width in the
README table, so 2× looks crisp). Trim browser chrome.

For the video: drag the file into any GitHub issue or PR comment, let it
upload, then copy the generated URL into the Demo section of the root README.
